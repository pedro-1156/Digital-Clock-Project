# Digital-Clock-Project
A simple digital clock made with **HTML, CSS, and JavaScript**.

## 🚀 Technologies
- HTML5
- CSS3
- JavaScript (DOM, Date, setInterval)

## ✨ Features
- Real-time digital clock
- Automatic **day/night theme** based on the current time
- Responsive layout with Flexbox

## 📚 What I learned
- DOM manipulation with JavaScript
- Using `setInterval()` to update time every second
- Working with the `Date()` object
- Changing CSS styles with JavaScript
- Flexbox layout and UI styling
- Organizing files into HTML, CSS, and JS

## 🎯 Purpose
This is a small educational project created to practice frontend development.
